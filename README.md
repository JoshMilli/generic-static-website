# Basecamp Chat Webhook + Analytics

This project now includes a small Node.js server that exposes a webhook endpoint for Basecamp chat events, stores them locally for analysis, and provides a lightweight analytics dashboard.

## What you get

- POST /webhooks/basecamp — payload URL to register as a Basecamp webhook
- GET /analytics.json — aggregated analytics (JSON)
- GET /analytics — simple dashboard with charts
- GET /healthz — basic health check

Events are appended to data/events.jsonl as JSON Lines (raw payload + normalized fields).

## Run locally

1. Install dependencies:

   npm install

2. Start the server:

   npm run dev

3. Your payload URL (for local testing with a tunnel like ngrok/localtunnel) will be:

   https://YOUR_TUNNEL_DOMAIN/webhooks/basecamp

   Without a tunnel, locally it is:
   http://localhost:3000/webhooks/basecamp

4. View analytics:

   http://localhost:3000/analytics

## Register the webhook in Basecamp

In Basecamp’s “Add a new webhook” screen:
- Payload URL: https://YOUR_DOMAIN/webhooks/basecamp
- Content types: select “Message” and “Client reply” (and any others you want)
- Enable the webhook

We store the full payload plus normalized fields (sender, message text, timestamps) for later analysis.

## Deploy

Any Node-friendly platform (Render, Railway, Fly.io, Heroku, etc.) will work.

- Set the start command to: npm start
- Expose port 3000 (or use PORT from the platform)
- After deploy, use https://YOUR_DOMAIN/webhooks/basecamp as your Basecamp Payload URL

## Notes

- This implementation does not rely on any Basecamp secret or signature verification (Basecamp does not document a signed webhook scheme). If you want to restrict access, consider adding an allowlist, a shared secret token in the path or header, or placing the endpoint behind an authenticated gateway.
- The summarization is intentionally simple (first sentence or 160 chars) and a naïve keyword extractor to keep dependencies light. You can swap this out for an LLM or a more advanced summarizer if desired.
